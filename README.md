# Zeroflow

**A native, lightweight macOS utility set — screenshot annotation, window switching, Dock enhancements, clipboard history and a Dynamic Island, all behind a single menu bar icon.**

---

No pop-ups, no third-party dependencies. Small package, fast launch, low idle memory.

Compared to AltTab (a window switcher) and Maccy (a clipboard manager), Zeroflow offers several times more functionality while using significantly less memory — both right after launch and after extended use. Download all three and see the difference for yourself.
